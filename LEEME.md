Un módulo es una forma de dividir un programa, es como un grupo funcional, y son reutilizables. Básicamente sirven para tener una mejor organización de todo el código, dividiéndolo en varias partes donde cada una se ocupa de una parte del programa en concreto.



2-

Una lista de exportación es una lista, que se debe escribir al principio de un módulo, y que contiene los elementos de otros módulos que queremos que sean accesibles desde este.



3-

Ocultar el constructor protege las invariantes porque se deben cumplir varias restricciones, como que el número de vidas no sea negativo. En este caso hemos ocultado el constructor pero no las funciones públicas, por tanto se pueden crear o editar jugadores pero que cumplan las restricciones que hemos impuesto en esas funciones
